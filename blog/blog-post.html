SynthoCare Risk Lab: Disease Risk Models Built on Synthetic Data

SynthoCare Risk Lab is an open project that shows how to build and demo multi-disease risk models using synthetic (computer-generated) patient-style data. It is made for learning, teaching, and pipeline practice—not for real clinical care.

Disclaimer: This project does not use real patient data. Models are not clinically validated. Do not use the app for diagnosis or treatment decisions.

Live Streamlit app:
https://synthocare.streamlit.app/

Why this project?

Real health records are private and hard to share. Students and developers still need realistic data to practice machine learning for chronic disease risk. Synthetic data solves that: you get practice data without exposing real people.

What is included?

  • Synthetic longitudinal patient data (labs, vitals, symptoms, diagnoses)
  • Machine learning models for multiple chronic conditions
  • A live Streamlit web app for interactive demos
  • Open-source code and documentation on GitHub

Conditions covered (synthetic labels)

  • Type 2 diabetes
  • Chronic kidney disease
  • Coronary artery disease
  • Heart failure
  • Hypertension
  • COPD
  • Chronic liver disease / MASLD
  • Rheumatoid arthritis
  • Hypothyroidism
  • Alzheimer’s / cognitive decline

How it works

  1. Generate synthetic patients and encounter-level features.
  2. Split data by patient into train, validation, and test sets.
  3. Train risk models for each disease.
  4. Deploy a Streamlit app that scores a simple input form.

The app uses age, lifestyle, blood pressure, symptoms, family history, and optional lab values to show demo risk scores. Scores are for education only.

How to try it

Online: Open the live app → https://synthocare.streamlit.app/

Code: Clone or browse the repo → https://github.com/Ganapathy-bot/synthocare-risk-lab

Local run: 

git clone https://github.com/Ganapathy-bot/synthocare-risk-lab.git
cd synthocare-risk-lab
pip install -r requirements.txt
streamlit run streamlit_app.py

Who is it for?

  • Students learning healthcare machine learning
  • Developers building safe demo pipelines
  • Teachers who need an interactive classroom example

Key takeaway

SynthoCare Risk Lab is a safe sandbox for practicing disease-risk modeling and demo UIs. Use it to learn. Do not use it for real patient care. Always keep the synthetic-data disclaimer when you share the project.
